# GitHub Upload Steps

1. Open GitHub.
2. Create a repository named `Daily-Food-Global-Intelligence`.
3. Keep the repository Public if using GitHub Pages.
4. Upload the complete contents of this folder, including hidden `.github` files.
5. Commit the files.
6. Open the repository's Actions tab.
7. Run the Pages workflow.
8. Wait for deployment to finish.
9. Open Settings → Pages.
10. Verify the GitHub Pages URL.
11. Run `workflow_dispatch` for the first Daily Intelligence update.
12. Add `OPENAI_API_KEY` under GitHub Actions Secrets if AI analysis is desired.

PostgreSQL, Vercel, Railway, Render, and Cloud Scheduler are not required.
